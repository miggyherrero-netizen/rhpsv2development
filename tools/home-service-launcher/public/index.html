How the code-review ratings work

Scores evaluate this task, not the agent overall: correctness, safeguards, maintainability, and verification, each 1–5 with equal weight. 1 = blocked; 2 = major gaps; 3 = useful with follow-ups; 4 = strong with limited gaps; 5 = fully demonstrated for its scope. An unverified check is marked as unverified, not passed. Documentation-only work is evaluated for its stated scope. Scores are provisional; runtime and database integration were not exercised for the historical PRs.
